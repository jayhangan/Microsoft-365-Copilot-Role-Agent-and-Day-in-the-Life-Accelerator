## 🤖 What Is an Agent?

Think of Microsoft 365 Copilot as a smartphone and agents as the apps that extend what the smartphone can do.

Microsoft 365 Copilot provides the broader AI experience, while an agent is configured to support a focused role, recurring task, business process, or information need.

An agent can be given:

- A defined purpose
- Detailed instructions
- Approved organizational knowledge
- Expected output formats
- Starter prompts
- Behavioral and human\-review requirements

The objective is not to replace the user’s professional judgment. The objective is to provide more focused, repeatable assistance for common work activities.

Do not attribute the smartphone\-and\-apps analogy to a named individual unless a verified public source is available.
